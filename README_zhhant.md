# 靈動照片

> **語言說明：** Android 版本目前暫不提供繁體中文；Android 介面目前仍為簡體中文。

靈動照片是一款面向 iOS 與 Android 的本機優先照片創作工具。iOS 版本使用 SwiftUI，Android 版本使用 Kotlin 與 Jetpack Compose。兩個版本都能從照片中提取感知色彩、辨識畫面內容、讀取真實拍攝資訊，生成卡片、色盤、手帳、印章、桌布、隱私遮擋、可掃描驗證的影像票根與多頁影像相簿，並透過「色彩關係」比較兩張照片的共同色、對照色與連接色階。iOS 亦提供面向一般使用者、容易理解的光影解析，可把照片轉為鉛筆、炭筆或水彩風格的影像素描，可選擇影片片段與封面來生成 Live Photo，並能以六張照片組成完整扇面的「流光摺扇」、用「節氣尋色」依二十四節氣收藏照片中的傳統色，以及透過「照片背面」留下畫面之外的回聲並約定再次回看。

**Android 安裝套件：** [下載已簽署 APK](https://locallens.cn/LingdongPhoto-Android.apk)

免費下載，無訂閱、無廣告；iOS 提供透過一次性購買取得的「支持我們」內容。照片辨識、色彩分析與作品算繪均在裝置上完成。

## Android 版本

Android 版本使用 Kotlin 與 Jetpack Compose 編寫，支援 Android 13 及以上系統。介面與互動針對 Android 裝置重新實作；照片處理不依賴專案伺服器，應用程式資訊清單亦不申請網路權限。

### 創作模式與導覽

- 尚未加入照片時，可左右滑動瀏覽七種創作模式，以及獨立的色彩關係、影像相簿與票根掃描入口。
- 載入照片後，可從頂端面板切換模式，並保留目前照片及其本機分析結果。
- 包含靈動卡片、琉璃色盤、一鍵手帳、氣泡印章、色譜桌布、隱私馬賽克與影像票根。

### 影像票根與驗證

- 把照片、標題、拍攝資訊、代表色與票根憑證組合成靜態 PNG 作品。
- 提供橫向經典、直向旅行與極簡憑證三種版式；橫向票根支援橫向預覽與編輯。
- 支援經典一維碼與驗證 QR Code，並可分別控制公開文案、時間、地點、裝置與鏡頭、拍攝參數及色盤。
- 提供標準模式與時光膠囊敘事，可填寫最多 80 字的票根寄語。
- 使用 Android Keystore 中的 P-256 裝置密鑰簽署 QR Code 公開資訊。
- 可在本機跨平台驗證 Android 與 iOS 生成的票根。
- QR Code 不包含原始照片、相簿識別碼、檔案路徑或裝置序號。

### 影像相簿

- 提供旅行、家庭、兒童、動物與自訂五類主題，以及 15 套模板。
- 支援 A5 直向、方形相簿與 A4 橫向三種尺寸。
- 可加入一般照片或靈動作品，編輯封面與頁面文字，新增、複製、刪除或調整頁面順序。
- 可預覽整本跨頁，並匯出電子版 PDF 或含 3 mm 出血的印刷 PDF。

### 色彩關係

- 使用 OKLab 感知色彩與加權色盤配對比較兩張照片。
- 提供「共鳴、對照、過渡」三種觀察方式。
- 根據照片方向自動安排雙橫圖、雙直圖或橫直混合版面，優先完整顯示影像。
- 顯示色彩親近、明暗距離與冷暖距離，並生成對應關係文案。
- 可匯出最高 2400 像素寬的比較圖，或最長邊最高 8192 像素的原圖級作品。

### 色彩、分析與匯出

- 以 OKLab 加權 K-Means 提取最多六種代表色，顯示 HEX 或文學色名及整圖占比。
- 使用 ML Kit 在本機辨識畫面，並讀取裝置、鏡頭、光圈、快門、ISO、焦距、時間與 GPS。
- 支援系統照片選擇器與其他應用程式的分享選單。
- 支援 JPEG、PNG、HEIC，以及 1080P、2K 與最高 6000 像素寬的原圖級輸出。
- 可完整保留中繼資料、只移除 GPS，或移除位置、裝置、鏡頭與原始拍攝時間。
- 支援讀取、預覽及儲存 Motion Photo；隱私馬賽克只匯出已處理的靜態畫面。

## 為什麼做這個專案

專案最初是一個實驗：從零開始製作一款精緻的小型照片工具究竟有多複雜？第一個 iOS 版本參考公開可見的互動形式，但沒有使用或反編譯任何第三方應用程式的原始碼、素材或私有資源。

它後來早已超出單純介面練習的範圍：目前包含 OKLab 感知色彩、加權 K-Means、色彩占比、雙照片色彩關係、Apple Vision 本機辨識、分類文案庫、真實 EXIF、Live Photo 動態匯出、光影解析、影片轉 Live Photo、多圖手帳、隱私遮擋、影像素描、可驗證影像票根、裝置封印、主應用程式掃描、App Clip、多頁影像相簿、節氣尋色、照片背面、照片操作延伸功能、App Shortcuts 與匯出中心。Android 則以適合該平台的技術獨立實作同一套核心流程。

市面上部分相似工具採用月費或買斷制，這是開發者的自由；本專案選擇公開實作過程，讓有興趣的人可以理解、修改與持續完善。

## iOS 功能

### 創作模式與介面

- 尚未加入照片時，可瀏覽十一種創作模式，以及流光摺扇、影像相簿、色彩關係、票根顯影、郵票製作、明信片、掃描驗證票根、影片轉實況、票根集、郵集、節氣尋色與照片背面等獨立工具。
- 獨立工具無需先進入主編輯器即可開啟；匯入照片後，也可從同一個模式面板切換創作模式或進入各項工具，無需重新選圖。
- 模式面板使用半透明 Liquid Glass，並跟隨系統淺色或深色外觀。
- 所有功能都會依 iPad 直向、橫向、大螢幕空間與可調整視窗重新安排預覽及操作區域，同時保留 iPhone 上熟悉而緊湊的操作體驗。
- 簡體中文與繁體中文介面會在引導流程結束後顯示「靈動照片 3.0 創作季」，也可透過 `lingdongphoto://home` 再次開啟。

### 靈動色卡與靈動月曆

- 靈動色卡從照片提取主色，色條可向下、向左或向右延伸；調整大小不遮擋、不裁切照片。
- 靈動月曆保留橫圖、直圖與方圖的原有比例，月曆面板等比配合畫面，並記錄拍攝日期與節氣。

### 節氣尋色

- 依照片原始拍攝時間歸入對應節氣，從照片代表色中配對傳統色，逐步點亮完整的節氣年。
- 每個節氣可收藏多張照片、選擇年度代表作，並查看完整十六色、節氣物候、詩詞與可考出處。
- 可生成階段或完整年度色譜，也可匯出收藏備份並在本機回復；日期讀取、照片取色與傳統色配對均在裝置上完成。

### 照片背面

- 從「畫面裡」、「畫面外」或「寫給以後」三個方向，為照片寫下沒有拍進畫面的回聲。
- 可約定再次查看的時間；照片到期後會重新浮現，也能繼續補寫一段「後來」。
- 正反面支援點按或輕掃翻轉，照片與文字會收進本機的照片抽屜。

### 流光摺扇

- 以六張照片組成完整展開的摺扇，每個扇面各自呈現一張照片。
- 「自動尋色」會在裝置本機從已授權照片中尋找並組合同一色系的六張照片。
- 「自由編排」可手動選擇最多六張照片，並逐個扇面換圖、拖曳與縮放，以精確調整取景。
- 成品可儲存為 2400 × 1800 的透明 PNG。

### 郵票、明信片與郵集

- 郵票製作提供五種齒孔模板，可加入照片、標題、日期與字型，並收藏或儲存為 PNG；「手動選取」支援直接拖曳與雙指縮放照片，以精確調整構圖。
- 明信片提供四種版式，可組合照片、寄語、郵票與郵戳。
- 郵集用於收藏帶定位的郵票、點亮城市足跡；長按郵票可自由旋轉。

### 票根收藏、顯影與檔案

- 票根集可將旅行、演出或某一段時光的影像票根整理分集。
- 票根顯影會在裝置本機智慧辨識匯入的實體票照片，並重製為可驗證的影像票根。
- 琉璃檔案以 Liquid Glass 檔案欄封存裝置、參數與座標的原始記錄；檔案欄可在照片中自由上下滑動，匯出時保留目前相對位置。

### 琉璃色盤與光影解析

- 在圖片上方流暢切換「琉璃色盤」與「光影解析」。

### 影片轉實況

- 從系統照片選擇器匯入影片，並在完整時間軸中選擇連續三秒作為 Live Photo 動態片段。

## 本機智慧與色彩提取

iOS 使用 Apple Vision 辨識 34 類畫面，包括人像、家庭、貓狗、鳥類、昆蟲、花園、森林、山景、海灘、天空、日落、城市、建築、街道、夜景、美食、咖啡、旅行、運動與文字截圖。辨識使用 `VNClassifyImageRequest`、`VNDetectFaceRectanglesRequest` 與 `VNRecognizeTextRequest`，不會把照片上傳至專案作者。

色盤流程如下：

1. 縮圖並取樣整張影像。
2. 將 RGB 轉為 OKLab。
3. 使用加權 K-Means 聚類代表色。
4. 將樣本分配至感知距離最近的色群。
5. 依像素權重計算整圖占比。
6. 把捨入誤差補至最大色群，使全部百分比合計為 100%。

文學色名同樣依 OKLab 最近距離，從 76 個參考色中選取。

## Liquid Glass 與 Live Photo

- iOS 26 使用原生 Liquid Glass API；iOS 17 與 18 使用相容磨砂材質。
- iOS 27 與 iPadOS 27 已完成系統級適配，包含可調整視窗與版面變化。
- iPhone 18 Pro 與 iPhone 18 Pro Max 已針對機身尺寸及動態島區域調整介面。
- 按鈕支援按壓縮放、彈性回應與觸覺回饋。
- 「減少動態效果」會略過非必要動畫。
- 系統照片選擇器只提供使用者主動選取的項目。
- 可從原始資料讀取 EXIF、TIFF 與 GPS。
- 可匯入、預覽、逐格合成並寫入配對的 Live Photo 影片。
- 匯入 Live Photo 後，會在使用者點按實況控制前於背景完成動態影格解碼與快取，首次預覽即可使用已準備好的播放內容。
- 動態影格與關鍵照片會統一轉為標準動態範圍，避免 HDR 明暗不一致。
- 缺少的相機資訊會保持空白，不會虛構固定型號、光圈或 ISO。

## 隱私

- 不需要帳戶，不包含廣告或第三方分析 SDK。
- 不收集照片、創作內容或裝置識別碼。
- 辨識、色彩計算與作品算繪均留在裝置上。
- 使用者匯入的相機品牌 PNG 只保存在應用程式本機。
- 驗證 QR Code 只包含創作者主動選擇公開的欄位。
- 裝置封印只簽署 QR Code 公開資訊；私鑰保留在安全隔區或 Android Keystore。
- 只有在使用者進入票根掃描器時才申請相機權限。
- 只有使用者明確儲存時才寫入系統「照片」。
- iOS 顯示地名時可能使用 Apple 系統地理編碼服務；Android 不包含地圖功能，也不申請網路權限。

能在本機完成的事情，就應該留在本機。

## 建置

### iOS

```bash
git clone https://github.com/LocalLens-Project/LingdongPhoto.git
cd LingdongPhoto
open lingdongzhaopian/lingdongzhaopian.xcodeproj
cp lingdongzhaopian/Config/Signing.local.example.xcconfig \
   lingdongzhaopian/Config/Signing.local.xcconfig
```

在 `Signing.local.xcconfig` 填寫 `DEVELOPMENT_TEAM`、主應用程式、延伸功能、App Clip、父應用程式及 App Group 識別碼。建立對應 App ID，讓主應用程式與照片操作延伸功能共用 App Group，並設定 App Clip 的父應用程式關聯。之後選擇 iOS 17+ 模擬器或實機執行。

公開儲存庫預設編譯 `SupporterStore.swift` 與 `TraditionalColorLexiconData.swift` 的非商業占位實作。取得相應商業授權並把商業原始碼保留在本機後，可在已被 Git 忽略的 `Signing.local.xcconfig` 加入：

```xcconfig
SWIFT_ACTIVE_COMPILATION_CONDITIONS = $(inherited) COMMERCIAL_BUILD
```

本機商業工程會因此排除公開占位宣告，改為編譯 StoreKit 與完整色彩資料；公開克隆版本則不會引用未發布內容。除 Onboarding 截圖／GIF 與兩張模式入口選擇截圖外，公開儲存庫中新加入的產品圖片資源均以商業授權提示圖占位，並保留原資源名稱以維持 Asset Catalog 可建置。

### Android

```bash
cd Android/lingdongzhaopian
./gradlew assembleDebug
```

Debug APK 會輸出至 `app/build/outputs/apk/debug/app-debug.apk`。如需簽署 Release，請建立只在本機使用的 `keystore.properties`，把密鑰放在已忽略的 `signing/` 目錄，再執行 `./gradlew assembleRelease`。

## 權限

- 一般 iOS 選圖使用系統 PhotosPicker，不需要完整相簿讀取權限。
- 相機權限只用於本機 QR Code 掃描。
- 從「照片」操作恢復 Live Photo 配對影片時，可能需要有限或完整照片讀取權限，以精確配對原始項目。
- 只有儲存靜態作品或 Live Photo 時才使用新增照片權限。
- App Clip 不申請照片讀寫、相機、位置或通知權限。
- Android 使用系統選擇器與暫時分享 URI，透過 MediaStore 寫入；只宣告相機與震動，不宣告網路、位置或麥克風權限。
